# AI 学习路由

别名：AI learning routing、学习路由。

> 核心洞察：学生不需要知道"现在该调哪个工具"——他只需要说**"继续"**。AI 自动读取进度状态，路由到正确的学习模块。

## 问题

AI 学习辅助工具越来越丰富（讲课、讲题、出题、复习、诊断…），但学生面对的是**工具选择困难**——60 分的学生最不会的就是"判断自己当前应该做什么"。

## 路由逻辑

```
学生说"继续"
    ↓
AI 读 进度/当前任务
    ↓
根据 阶段 + 方式 + 上次会话 → 自动选择模块
    ↓
直接进入学习，不让学生选
```

### 路由表

| 任务状态 | 路由到 |
|---------|--------|
| 阶段: 病因级 + 方式: 讲课 | 讲课（从头讲概念） |
| 阶段: 联结修复 + 方式: 讲题 | 讲题（打通推导链/变式题） |
| 阶段: 熟练强化 + 方式: 出题 | 出题（大量练习形成条件反射） |
| 会话记录显示昨天未完成 | 对应模块（续上次） |
| 状态: 已完成（无下一个任务） | "全部完成，要不要重新诊断？" |
| 进度为空（从未诊断） | "要不要先诊断一下？" |

## 教师在环的实践原型

[2026-09-10 AI 时代学校与专业重构构想](<../../教育/教育与技术/2026-09-10 AI 时代学校与专业重构构想.md>) 记录了一个更完整的应用：教师把知识体系、考点体系和方法交给 AI，配合按段位分配题目的练习网站与学情记录，在电脑室观察学生使用，再持续优化。学习路由因此不只是“根据状态跳转模块”，还包括教师对任务、干预和系统效果的持续管理。

## 设计原则

- **"继续"是默认入口**，手动触发（"讲课 XX"/"讲题"/"出题"）仍保留，用于学生想跳过当前任务
- 路由逻辑放在 AGENTS.md 的每日行为中，不新增独立 Skill
- 用户不需要理解路由——只需要说一件事
