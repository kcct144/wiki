# 青年助手 v5 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 基于 SRS 间隔重复，提醒用户复习到期词汇。

---

### SRS 算法

```
记住：连对 1→1d, 2→3d, 3→7d, 4→15d, 5→30d, 6+→min(×1.5, 90d)
没记住：连错 1→max(间隔/2, 1d), 2→max(间隔/3, 1d), 3+→1d
下次复习 = 今天 + 新间隔
```

- `streak` 记录连续记住次数，`连对` = streak
- `连错` = streak 归零后连续没记住的次数
- 最大间隔上限 90 天

### 复习卡片

每个到期词以闪卡形式展示：

```
┌─────────────────────┐
│                     │
│    challenge        │  ← 正面：仅英文
│                     │
└──────────点击翻转────┘

┌─────────────────────┐
│  challenge          │
│  /ˈtʃæl.ɪndʒ/       │  ← 背面：英文 + 音标
│                     │
│  n. 挑战、困难       │  ← 释义堆（合并同词性）
│  v. 质疑             │
│                     │
│  ─── 2 个义项 ───    │  ← 义项数
│                     │
│  [记住了]  [没记住]   │  ← 自评按钮
└─────────────────────┘
```

### 场景

1. 用户进入复习 → 展示今日到期列表
2. 只展示状态为 **学习中** 的词，已掌握和不重要的词不出现
3. 点击卡片 → 翻转显示背面
4. 用户自评：**记住了** / **没记住**
5. 全部评完后 → 显示结果统计（X/Y 正确）
6. SRS 字段自动更新，下次复习按新间隔计算

### 复习模型（复用 Word 的 SRS 字段）

```
Word 上的 SRS 字段
  ├── interval: number        # 当前间隔（天）
  ├── next_review: date       # 下次复习日期
  ├── review_count: number    # 复习总次数
  └── streak: number          # 连续记住次数
```
