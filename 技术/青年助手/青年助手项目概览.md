# Youth-Assistant

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 在你看喜欢的英文内容时，它帮你记生词、拆长句、收语法，每天自动安排复习。学英语是顺便的事。

## 项目信息

| 项目名称 | Youth-Assistant |
| ---- | ----------------------------------------------- |
| 定位   | 面向初高中生的英语精读、泛读助手 |
| 理念   | 材料驱动，不是背单词驱动。用户在喜欢的英文材料（音乐、视频、文章）中自然积累词汇和语法 |
| 技术栈  | 前端框架：Next.js<br>AI 框架：待定<br>数据库：MySQL |

## 原项目的设计约定（历史）

本知识库仅保留各版本的需求方案，按专题平铺为 Markdown 文档。以下是原项目的目录约定。

每个版本独立文件夹，包含：

| 文件 | 内容 |
|------|------|
| `spec.md` | 功能规格 |
| `plan.md` | 执行计划（朋友维护） |
| `log.md` | 交付记录 + 踩坑 |
