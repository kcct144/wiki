# 青年助手 v7 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 阅读体验完善：教材主线（主线程）、书架（想读+收藏）、阅读状态标记。

---

## Module 1 — 教材主线

### 概述
教材精读是用户的主线任务。用户选择学段（关闭/初中/高中），系统按教材系列 → 课文顺序推进，类似主线任务。其他材料（音乐/视频/文章）是支线，用户自由浏览。

教材主线与支线材料**互不干扰**——各自独立入口、独立进度。

### 学段设置
用户可在设置中选择：
- **关闭**：不使用教材功能
- **初中**：精读初中教材课文
- **高中**：精读高中教材课文

切换学段后自动切换到对应教材系列列表。

### 场景
1. 用户进入"教材"入口 → 看到当前学段的教材系列列表
   - 高中：必修1 → 必修2 → 必修3 → 选必1 → ...
   - 初中：七年级上 → 七年级下 → 八年级上 → ...
2. 每个系列显示完成进度（已精读 N/M 课）
3. 展开系列 → 按顺序展示各课
4. 每课显示状态标签：未开始 / 已泛读 / 已精读
5. 用户逐课推进，完成后自动定位到下一课
6. 教材课文同样支持标注（复用 v4 段落模式加词 + 回注）

## Module 2 — 书架（想读 + 收藏）

### 概述
用户的个人材料管理。两个列表：**想读**（还没读、打算读的）和**收藏**（读过了觉得好的）。在材料卡片上可一键加入任一个。

### 说明
想读和收藏是标记在 `user_material` 上的两个独立布尔字段（`is_want_read`、`is_favorite`）。点击图标时如果该材料尚未拥有用户副本，自动创建 `user_material` 并复制原始正文（与 v2 阅读视图的创建逻辑一致）。

### 场景
1. 在材料列表或阅读视图中 → 点击"想读"或"收藏"图标
2. 如果该材料尚无用户副本 → 自动创建（触发时机同 v2：第一次打开/操作该材料时）
3. **想读列表**：展示用户标记为"想读"的材料，按添加时间倒序
4. **收藏夹**：展示用户标记为"收藏"的材料
5. 再次点击取消对应状态
6. 同一个材料可同时在想读和收藏中（读完了想读→收藏）

---

## Module 3 — 阅读状态标记

### 概述
用户读完材料后自己勾选阅读状态。仅对支线材料有效（教材主线有独立的进度系统）。

### 场景
1. 阅读支线材料时或完成后 → 点击"标记状态"
2. 选项：已泛读（读过一遍）、已精读（逐句读过）
3. 标记后材料卡片显示状态标签
4. 可按状态筛选列表

### 状态语义
| 状态 | 含义 |
|------|------|
| 未读 | 还没打开过 |
| 已泛读 | 读过一遍，了解了内容 |
| 已精读 | 逐句读过，标注了生词和长句 |
