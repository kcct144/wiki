# 0.6 Spec — 周测

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 每周一套题：完形填空 + 阅读理解。完形匹配最近学的词，阅读匹配最近读的话题。

---

## Module 1 — 组卷

### 概述
系统根据用户最近积累的词汇和阅读话题，从题库中匹配题目，自动组卷。

### 组卷规则

**完形匹配**
1. 取最近 7 天新增的词汇
2. 扫描题库完形题 → 找 target_words 命中率最高的 1 篇
3. 近 14 天做过的完形不重复出现

**阅读匹配**
1. 取最近 7 天读过的材料话题
2. 扫描题库阅读题 → 找 topics 命中率最高的 1 篇
3. 近 14 天做过的阅读不重复出现

**兜底**
- 无命中 → 从题库随机取



---

## Module 2 — 答题与批改

### 场景
1. 用户进入周测 → 看到组好的卷子
2. 逐题作答
3. 提交 → 系统批改 → 显示分数（X/Y）
4. 每道题显示正确答案和解析


---
