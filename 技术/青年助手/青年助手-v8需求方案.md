# 青年助手 v8 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 用户在阅读中遇到看不懂的句子，选中 → AI 拆解语法结构 → 入库 → 加入复习。

---

## Module 1 — 句子收集

### 概述
在阅读视图中按句子粒度收集看不懂的句子，保存到句子本。交互方式与 v4 加词统一：段落 hover 后选择句子。

### 场景

段落 hover 后显示两个操作按钮：

```
┌────────────────────────────────────────────┐
│ This is a challenging problem that requires│  [A]  [S]
│ creative thinking. But I don't know how    │
│ to solve it.                               │
└────────────────────────────────────────────┘
```

- `[A]` → 加词模式（v4），每个单词变按钮
- `[S]` → 存句模式，每个句子变按钮

点击 `[S]` → 段落进入**存句模式**，段落按句号/问号/感叹号分割，每个句子变成可点选的区块：

```
┌────────────────────────────────────────────┐
│ ┌────────────────────────────────────┐     │
│ │ This is a challenging problem     │ [+]│  ← 可点选，灰色=未选
│ │ that requires creative thinking.  │     │
│ └────────────────────────────────────┘     │
│                                            │
│ ┌────────────────────────────────────┐     │
│ │ But I don't know how to solve it.  │ [✓] │  ← 蓝色=已选
│ └────────────────────────────────────┘     │
│                                            │
│     已选 1 句    [确认存句]  [取消]          │
└────────────────────────────────────────────┘
```

1. 点选句子（再次点击取消）
2. 选完后点击"确认存句" → 展示确认窗口，可手动填入翻译或笔记
3. 用户也可选择暂不填翻译，直接入库
4. 保存 → 句子入库，后续可在句子本中查看

文本选中存句作为辅助方式保留（详见 v4 选中菜单）。

## Module 2 — AI 句子拆解

### 概述
对已保存的句子，AI 自动标注语法结构。用户可随时查看拆解。

### 场景
1. 在句子列表中点击某条句子 → 进入详情
2. 点击"AI 拆解" → 系统调用 AI 分析语法结构
3. 展示：
   - 基本信息：句型、时态、主语、谓语
   - 缩进拆解：每行一个成分 + 括号标注语法角色
   - 阅读建议：意群停顿标注
4. 拆解结果可收藏或忽略

## Module 3 — 句子复习

### 概述
句子有独立的复习入口，与词汇复习互不干扰。共用 v5 的 SRS 算法，但卡片设计不同。

### 复习卡片

```
┌────────────────────────────────────┐
│                                    │
│  This is a challenging problem     │  ← 正面：英文原句
│  that requires creative thinking.  │
│                                    │
└───────────────点击翻转──────────────┘

┌────────────────────────────────────┐
│  This is a challenging problem     │
│  that requires creative thinking.  │
│                                    │
│  这是一个需要创造性思维的挑战性问题。│  ← 背面：翻译/笔记
│                                    │
│  [查看笔记]                        │  ← 展开 AI 拆解详情
│                                    │
│  [记住了]  [没记住]                 │
└────────────────────────────────────┘
```

### 场景
1. 从独立入口进入句子复习 → 展示今日到期句子列表
2. 点击卡片翻转 → 显示翻译/笔记
3. 可点击"查看笔记" → 展开 AI 拆解详情
4. 自评后更新 SRS 间隔（复用 v5 的 SRS 算法）

### 句子模型

```
Sentence
  ├── id: number
  ├── user_id: number
  ├── material_id: number       # 来源材料
  ├── content: text             # 原句
  ├── translation?: text        # 翻译
  ├── note?: text               # 用户笔记
  ├── decomposition?: text      # AI 拆解结果（JSON）
  └── SRS 字段（与 Word 共用同一套字段：interval, next_review, review_count, streak）
```
