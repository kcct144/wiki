# 青年助手 v2 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 开发者预置材料，用户像逛视频网站一样浏览、打开、阅读。材料是词汇的来源场景。

---

### 数据组织

材料分两层：**系列 → 材料**。零散材料不属任何系列，独立存在。

```
系列（一本书、一部剧、一个栏目）
  └── 材料（课、集、篇）

零散材料（单篇文章、单首歌）
```

示例：

| 系列 | 材料 |
|------|------|
| 必修1 | Unit1 Reading, Unit1 Writing, Unit2 Reading... |
| 小猪佩奇 | Episode 1, Episode 2... |
| 科普宇宙系列 | 视频1, 视频2... |
| —（零散） | 单篇文章、单首歌 |

### 场景

**浏览材料库**
1. 用户进入材料页面 → 看到分类导航
2. 可按**类型**筛选（音乐/视频/文章/课文）
3. 可按**系列**浏览 → 展开系列 → 看到该系列下的材料列表
4. 可按**标签**筛选（如"环保""科技""励志"），标签跨系列
5. 支持组合筛选：类型 + 标签 + 系列
6. 零散材料单独列出
7. 每个材料卡片显示：标题、类型图标、所属系列、标签
8. 空状态提示（暂无材料）→ 由开发者后台添加

**阅读材料**

阅读视图整体布局：


两侧栏均可独立折叠，展开时正文自适应宽度。

1. 点击材料 → 进入阅读视图
2. 如果该材料用户尚未拥有副本 → 自动将原始正文复制为用户的 `body_md`（markdown）
3. 如果有视频链接 → 顶部嵌入 B站播放器
4. 标题栏显示今日学习进度：今日收集词数
5. 左侧可折叠侧栏展示进行中的任务和今日任务
6. 右侧可折叠侧栏为 AI 对话面板，阅读中随时提问（语法、词义、句子结构等）
7. 正文选中、标注、回注由 v4（阅读标注）实现

### 材料模型

```
Material
  ├── title: string
  ├── type: 音乐 | 视频 | 文章 | 课文
  ├── tags: string[]         # 标签数组，如 ["环保", "科技"]
  ├── series_id?: number     # 所属系列（null = 零散）
  ├── video_url?: string     # B站嵌入链接
  ├── body: text             # 正文，以空行分隔段落。原文不可变，回注由 v4 叠加
  └── created_at: datetime
```

```
Series
  ├── name: string
  ├── description?: string
  └── sort_order: number
```
