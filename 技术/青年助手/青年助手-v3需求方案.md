# 青年助手 v3 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 生词/短语管理。数据模型：一个**生词**对应多个**义项**。每次加词创建一个义项（释义 + 例句 + 翻译 + 来源）。同一个词的不同来源积累多个义项。

---

### 数据模型

```
Word（生词）
  ├── word: "challenge"
  ├── phonetic: "/ˈtʃæl.ɪndʒ/"  # 音标
  ├── status: 学习中              # 学习中 | 已掌握 | 不重要
  └── SRS 字段（interval, next_review, review_count, streak）

Sense（义项）
  ├── word_id: 1
  ├── pos: n.                # 词性
  ├── meaning: 挑战           # 释义
  ├── example: Going...**challenge**.  # 例句，生词本身加粗
  ├── translation: 从初中      # 例句翻译
  └── source: 必修1 Unit1     # 来源（材料标题）
```

- 同一生词的所有义项共享一个 SRS 状态
- 前端展示释义时，同词性释义合并，格式：`n. 挑战、困难；v. 质疑、怀疑`

### 场景

**手动加词**
1. 在词库页点击"加词" → 输入单词/短语
2. 系统自动获取释义、词性、音标（AI 查义）
3. 用户可手动补充例句、翻译、来源
4. 保存 → 生成一个义项：
   - 如果生词**不存在** → 创建生词（含音标）+ 第一个义项
   - 如果生词**已存在** → 追加新义项（不覆盖旧义项）

**词库管理**
1. 词库列表：展示所有生词
2. 每项显示：单词、音标、释义堆（合并所有义项的 `词性. 释义`）、状态、义项数
3. 点击生词 → 进入详情 → 展示音标、所有义项及其例句/来源
4. 每个生词可切换状态——"学习中"、"已掌握"、"不重要"，三种状态平级切换，没有删除操作
