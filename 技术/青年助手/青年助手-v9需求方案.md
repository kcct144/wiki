# 青年助手 v9 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 语法笔记与任务系统联动，精读后写英文读后感。v9 是 1.0 前最后一个版本，整合三个独立功能。

---

## Module 1 — 笔记模块

### 概述
用户创建语法笔记，从读过的材料中收集例句归到对应笔记。

### 场景

**创建笔记**
1. 用户说/点"记个语法：定语从句" → 系统创建笔记
2. 笔记包含：语法名称、英文名、类别、基本规则（不超过 3 条）
3. 自动检查已有笔记 → 检测易混淆配对（如定语从句 vs 同位语从句）

**收集例句（阅读中）**
1. 阅读时，左侧侧栏展示进行中的任务列表（如"收集 6 个定语从句例句 2/6"）
2. 点击某个任务 → 进入**收集模式**，该任务高亮，其他任务淡化
3. 在正文中选中文本 → 弹出菜单 → "提交到任务"
4. AI 判断所选文本是否符合任务标准：
   - ✅ 符合 → 例句收入笔记，关联任务 progress +1
   - ❌ 不符合 → AI 给出原因，用户可重新选择或取消
5. 每个例句记录原文、来源材料、日期
6. 退出收集模式后侧栏恢复正常展示

**查看笔记**
1. 笔记列表：展示所有语法笔记及例句进度
2. 笔记详情：基本规则、例句列表、容易混淆的语法点

**标记已掌握**
1. 例句收集达到目标数 → 用户可标记"已掌握"
2. 标记后关联任务自动完成

## Module 2 — 任务模块

### 概述
三类任务：一次性（ongoing）、限时（deadline）、定期（recurring）。任务与笔记联动。

### 任务模型
| 类型 | 说明 | 完成条件 |
|------|------|---------|
| ongoing | 一次性任务，无时间限制 | progress >= target |
| deadline | 有限期任务 | 截至日期前完成 |
| recurring | 每日/每周重复 | 当天完成 → 更新 last_done |

### 场景

**自动创建**
- 创建语法笔记时 → 自动生成一个 ongoing 任务（如"收集 6 个定语从句例句"）
- target 值系统根据语法复杂度、出现频率、用户当前负担综合判断

**手动创建**
- 用户自定义任务："加个任务：每天背 10 个词"
- 指定类型和目标数

**查看任务**
1. 任务列表按状态分组：今日待完成 / 进行中 / 已到期
2. 每个任务显示标题、进度（X/Y）、截止日期（如有）

**完成任务**
- 例句收集到笔记 → 关联任务 progress +1
- AI 每次提交时验证是否符合标准，不符合不计数
- progress >= target 且用户确认 → 标记 done
- 定期任务当天完成后更新 last_done

## Module 3 — 读后感

### 概述
精读/泛读完成后，用户用英文写感想，AI 纠正语法错误，不改内容。

### 场景
1. 阅读材料 → 点击"写读后感"
2. 显示 2-3 个引导问题（由浅入深：感受 → 观点 → 关联）
3. 用户在文本框内写英文
4. 提交 → AI 检查语法错误
5. 展示修正对照表（原文 vs 建议）
6. 用户确认 → 追加到该材料的用户副本（`body_md`）末尾，与回注共同保存在用户自己的 markdown 中

### 引导问题规则
| 轮次 | 方向 | 示例 |
|------|------|------|
| 第一轮 | 感受 / 内容 | Did you like it? What part stood out? |
| 第二轮 | 观点 / 理由 | Why do you think the writer said that? |
| 第三轮 | 关联 / 延伸 | Have you ever felt something similar? |

不固定顺序。每次从当前轮次取 2 个问题展示。

### 修正规则
- 只改语法错误（时态、单复数、冠词、语序）
- 不改表达风格和内容
- 学生原文保持原样，修正放在对照区
