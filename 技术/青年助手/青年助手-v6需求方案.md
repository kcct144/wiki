# 青年助手 v6 需求方案

背景：青年助手的历史设计记录；方案阶段以文档版本和正文说明为准。

> 用户首页，登录后第一眼看到的地方。聚合各模块数据做展示。v6 先放骨架，后续版本逐步加内容。

---

### 场景

1. 用户登录后 → 进入仪表盘
2. 显示四个数字卡片：
   - **已添加**：词库总词数
   - **已掌握**：标记为已掌握的词数
   - **待复习**：今日到期未复习的词数（仅统计状态为"学习中"的词，已掌握和不重要不计入）
   - **今日收集**：今天新加的词数
3. 快捷入口：去复习、去阅读、去词库
4. 后续版本逐步增加：任务进度、笔记进度、连续天数等

### 数据来源

| 卡片 | 来源模块 |
|------|---------|
| 已添加 | v3 词汇系统 |
| 已掌握 | v3 词汇系统 |
| 待复习 | v5 复习 |
| 今日收集 | v3 词汇系统 |
