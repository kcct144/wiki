### K02 平方根

如果一个数 x 的平方等于 b，即 x² = b，那么 x 叫作 b 的平方根。

在实数范围内：

- b > 0：有两个平方根，分别为 √b 与 −√b，互为相反数，和为 0。
- b = 0：只有一个平方根，就是 0。
- b < 0：没有平方根。

用户概括：“平方根一正一负……加起来为零？”讨论补充：必须限定为“正数的两个平方根”。

### K03 算术平方根

如果非负数 x 满足 x² = b，那么 x 是 b 的算术平方根，记作 √b；实数范围内要求 b ≥ 0，且 √b ≥ 0。

| 表述 | 示例 | 注意 |
|---|---|---|
| 9 的平方根 | 3 和 −3，合写为 ±3 | 正数有两个平方根 |
| 9 的算术平方根 | 3 | 只取非负的那个 |
| √9 | 3 | 根号本身表示算术平方根，不能写成 ±3 |
| √0 | 0 | 非负不等于正，不能漏掉 0 |

术语为“算术平方根”，不是“算数平方根”。

给学生的提问：“哪个非负数，自己乘自己等于这个数？”

### K04 立方根与根指数（随题补充）

如果 x³ = c，那么 x 是 c 的立方根，记作 ∛c。负数也有立方根，例如 (−2)³=−8，所以 ∛(−8)=−2。

根号左上角的数叫作根指数：算术平方根的根指数是 2，通常省略；立方根的根指数是 3，不能省略。根指数与根号内的被开方数位置不同。

### K06 数轴上的坐标与距离（随题补充）

- 坐标可以是负数，距离非负。坐标为 a 的点到原点的距离为 |a|；当 a<0 时，|a|=−a。
- 数轴上坐标为 x、y 的两点间距离是 |x−y|。位置明确时，可直接用“右边坐标减左边坐标”。
- 两点在原点两侧时，两点间距离等于各自到原点的距离之和，不能直接把两个带符号的坐标相加。

## 考点体系

### T01 已知同一个正数的两个平方根，求参数

- 关联知识：K02。
- 识别条件：题目明确给出一个正数的两个平方根。
- 核心依据：两个平方根互为相反数，和为 0。
- 解题流程：确认条件 → 两个表达式相加等于 0 → 解方程 → 代回检查。

**已练题 E01**：如果一个正数的平方根是 a+1 和 −3，求 a。

用户独立作答：a+1−3=0，得到 a=2。答案及依据正确。

讲解写法：因为同一个正数的两个平方根互为相反数，所以 (a+1)+(−3)=0，解得 a=2。

补充检查：代回得到 3 和 −3，它们的平方均为 9，符合题意。

教学提示：先让学生说明为什么可以列“和为零”，再计算；不要只记题目外形。

### T04 求正无理数的整数部分与小数部分

- 关联知识：K03、K05。
- 核心关系：正数的小数部分 = 原数 − 整数部分。例如 1.58 = 1 + 0.58。
- 解题流程：找相邻完全平方数 → 夹住根式 → 对整个表达式确定相邻整数范围 → 原数减去整数部分 → 代入求值。
- 小数部分可以用含根号的式子精确表示，不必先算出小数展开；检查它应在 0 与 1 之间。

**讲解题 E02（用户截图）**：设 √21−3 的整数部分为 a，小数部分为 b，求 a−b。

因为 4² < 21 < 5²，所以 4 < √21 < 5，进而 1 < √21−3 < 2。

因此 a=1，b=(√21−3)−1=√21−4，a−b=1−(√21−4)=5−√21。

用户卡点：询问“小数部分怎么求”，尚未提供独立解答。教学时先用有限小数解释“原数减去整数部分”，再迁移到根式。

易错点：把 √21 的整数部分 4 当成整个表达式的整数部分；以为小数部分必须写成 0.xxx；计算 a−b 时漏掉括号。

### T05 根据根的名称确定根指数，再代入求值

- 关联知识：K03、K04。
- 识别条件：根指数中含参数，题干指明该根式表示算术平方根或立方根。
- 解题流程：辨认左上角的根指数 → 分别对应 2、3 → 解出参数 → 代入目标式 → 求立方根。

**收录题 E03（用户截图）**：如果 $\sqrt[b-1]{a+2b}$ 为 a+2b 的算术平方根，$\sqrt[a-2]{1-a^2}$ 为 1−a² 的立方根，则 −a−b 的立方根为多少？

按题目所指的根式类型，b−1=2，a−2=3，得 b=3，a=5。于是 −a−b=−5−3=−8，其立方根为 −2。

代回检查：a+2b=11≥0，算术平方根有意义；1−a²=−24，负数可以开立方。

易错点：

- 将左上角的根指数看成根号前的系数。
- 忘记平方根的根指数 2 通常省略。
- 把平方根的被开方数非负限制误用到立方根。
- 求出 −a−b=−8 就停下，漏掉题目最后要求的“立方根”。

教学提示：先让学生指出“根指数”和“被开方数”，再将根的名称翻译为指数条件。

用户认为此题典型并要求收录，未提供独立解答；不据此认定已掌握。

### T06 数轴上含字母的两点间距离

- 关联知识：K06。
- 解题流程：读图判断左右及正负 → 右边坐标减左边坐标（或写差的绝对值） → 根据位置化简。

**错题 E04（用户截图）**：A 在原点左侧，坐标为 a；B 在原点右侧，坐标为 3√5，求 AB 的距离。

截图作答：选 D（3√5+a），判错；正确选项为 B（3√5−a）。用户反馈“刚刚被坑到了”，未说明原始推理。

解法一：右边坐标减左边坐标，AB=3√5−a。

解法二：由 a<0，AO=|a|=−a；OB=3√5。所以 AB=AO+OB=−a+3√5。

> [!assumption] 待确认的错误原因
> 可能把坐标 a 直接当作 AO 的长度，导致将两段距离相加时写成 3√5+a。选项能支持这一诊断方向，但用户尚未确认具体想法。

教学用具体数检验：若 a=−2，则 AO=2，AB=3√5+2；公式 3√5−a 正好变为 3√5−(−2)=3√5+2。

易错点：以为“两边的距离相加”等于“两边的坐标相加”；以为式子前面有负号就一定是负数（a<0 时 −a>0）。

### T07 数轴上指定区间内的整数点计数

- 所属小节：S02；关联知识：K06。涉及无理数端点时关联 K05 的估算与夹逼。
- 用户主动归纳题型：“找整数点数量的”。
- 解题流程：确定端点数值或范围 → 确认端点是否计入 → 找出最小和最大符合条件的整数 → 列举或计数。

### T08 根据数轴判断符号，化简含绝对值的代数式

- 所属小节：S02；关联知识：K06、K08、K09。
- 规则：绝对值内的整体非负时原样保留，为负时取其相反数。取相反数要对整个式子操作：−(a−b)=b−a。
- 解题流程：读出大小关系 → 判断每个绝对值内部整体的符号 → 去绝对值并保留必要括号 → 去括号、合并同类项。

**收录题 E06（用户截图）**：数轴上 a<b<0<c，化简 $|a-b|-|c-a|-|a|$。选项 A：2b−a；B：b−c+a；C：−a+b+c；D：a−2c。

因为 a−b<0，c−a>0，a<0，所以：

$$
|a-b|-|c-a|-|a|=(b-a)-(c-a)-(-a)=b-a-c+a+a=b-c+a。
$$

结果为 B。截图中 B 有选中边框，但没有网站判分标记；答案由本次计算核对正确。用户未提供解题过程，不推定具体使用了哪种方法或是否独立完成。

易错点：

- 只看 a、b 各自正负，不比较大小，误判 a−b 的符号。
- 将“取相反数”理解成随意改一个符号；应写 −(a−b)。
- 忘记绝对值外的减号：−|a|=−(−a)=a，而不是 −a。
- 去掉 (c−a) 前的减号时漏变号；−(c−a)=−c+a。

教学提示：先单独列出三个绝对值的结果，再代回原式，避免同时处理内外符号。后续检验可交换 a、b 的左右位置，检查是否重新判断 a−b 的符号。

学习记录：已看到正确选项被选中，已提供完整讲解；符号判断过程与迁移能力待验证。

### T09 用几何长度在数轴上表示无理数

- 所属小节：S02；跨小节关联：S26。知识关联：K03、K05、K06、K10。
- 解题流程：用勾股定理求线段长度 → 根据同圆半径相等确定数轴上的距离 → 确认圆心坐标与交点方向 → 圆心坐标加减半径。

**收录题 E07（用户文字与截图）**：以数轴的单位长度线段为边作正方形，以表示数 1 的点为圆心，正方形对角线长为半径画弧，交数轴于 A。图示正方形底边为 0 到 1，A 位于 0 左侧，求 A 表示的数。

正方形边长为 1，对角线是两直角边均为 1 的直角三角形的斜边，由勾股定理得对角线长 √(1²+1²)=√2。

画弧把这段长度转到数轴上，所以 A 到表示数 1 的点的距离为 √2。A 在圆心左侧，坐标为 1−√2。因 1<√2<2，故 −1<1−√2<0，与图示位置一致。

易错点：把半径当成 A 到原点的距离而答 −√2；忽略圆心为 1；忽略方向而答 1+√2；把正方形对角线长误认为 2。

教学提示：“画弧转移的是长度，最后要求的是坐标。”一般地，圆心坐标为 p、半径为 r>0，左右交点坐标分别为 p−r、p+r。

学习记录：用户将此题作为另一类题提供，未给出作答；已讲解，独立求解待验证。后续可改变圆心位置或交点方向，检查是否仍能从距离转为坐标。

### T10 数轴上关于某点对称求坐标

- 所属小节：S02；关联知识：K06、K08。
- 核心关系：B、C 关于 A 对称，则 A 是 BC 的中点，AB=AC。若坐标分别为 b、c、a，则 b+c=2a，故 c=2a−b。
- 解题流程：确认对称中心 → 写两侧距离相等或中点关系 → 求坐标 → 对照图中顺序检查。

**收录题 E08（用户文字与截图，条件待补）**：A、B 表示的数分别为 2 和〔数值未显示〕，B 关于 A 的对称点为 C，求 C 表示的数。图中顺序为 0<C<A<B。

设 B 的坐标为 b，C 的坐标为 c。由 AB=AC，得 b−2=2−c，所以 c=4−b。缺少 b 的具体数值，不能给出唯一数值答案；不能根据示意图长度猜数值。

教学解释：从 A 向右走 b−2 到 B，向左走同样距离到 C，因此 C 的坐标是 2−(b−2)=4−b。

易错点：误当作关于原点对称，直接将 b 变成 −b；把中心到点的距离当成对称点坐标；忽略减去整个括号时的变号。

知识联系：关于原点对称是 a=0 的特殊情况，此时 c=−b，两个坐标互为相反数。关于一般点对称时，两坐标的和等于中心坐标的两倍，不一定为 0。

学习记录：用户提供新的题型，未给出作答；通用方法已讲解，原题等待补齐 B 的数值，掌握程度待验证。
