# 中考英语题型分类学（材料笔记）

别名：中考题型分类、英语七大题型。

> 基于 YouthStudy 项目对广东中考英语 7 大题型的系统分类，含题型特征、考点映射和难度分级。

## 摘要

### 七大题型总览

```
英语题型
├── 题型一  语法选择    — 短文 + 10空 × 3选1   — 语法知识
├── 题型二  完形填空    — 短文 + 10空 × 4选1   — 词汇·推理
├── 题型三  阅读理解    — 短文 + 5题 × 4选1    — 阅读能力
│   ├── 应用文（海报/通知）
│   ├── 说明文/议论文
│   └── 记叙文
├── 题型四  配对阅读    — 左N ↔ 右M（M>N）   — 信息匹配
├── 题型五  短文填空    — 短文 + 词库(M选N，需变形) — 词汇·语法
├── 题型六  回答问题    — 阅读 → 写完整句子   — 阅读·表达
└── 题型七  书面表达    — 思维导图 → 短文写作  — 写作能力
```

### 题型特征

| 题型 | 题量×分值 | 核心考点 |
|------|:---------:|----------|
| 语法选择 | 10×1分 | 连词/代词/时态语态/介词/比较级/非谓语/物主代词/冠词 |
| 完形填空 | 10×1分 | 语境理解+词汇辨析（近年以语境型为主） |
| 阅读理解 | 15×2分 | 细节理解/推理判断/主旨大意/词义猜测 |
| 配对阅读 | 5×1分 | 信息匹配能力 |
| 短文填空 | 10×1.5分 | 词汇+语法+变形（词库选词填空） |
| 回答问题 | 5×2分 | 阅读+书面表达 |
| 书面表达 | 1×15分 | 综合写作能力 |
