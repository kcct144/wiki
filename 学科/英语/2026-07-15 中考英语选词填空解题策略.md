# 中考英语选词填空解题策略（材料笔记）

别名：短文填空策略、词性定位法。

> 基于 YouthStudy 项目整理的选词填空（短文填空）解题参考。核心策略：**看搭配 → 看词性 → 看句意**。

## 摘要

### 基本思路

1. **看搭配** — 固定搭配优先（如 be interested in, look forward to）
2. **看词性** — 根据空格位置判断缺少什么词性
3. **看句意** — 最后才靠意思确认

### 词性定位表

| 词性 | 大概率出现位置 | 例子 |
|------|------|------|
| 名词 | 形容词后 / 限定词后 | a good **boy** |
| 限定词 | 形容词前 / 名词前 | **a** good boy |
| 形容词 | 名词前 / 系动词后 | a **good** boy / I am **happy** |
| 动词 | 主语后 / 助动词后 / 非谓语搭配 | I **see**. / want to **go** |
| 连词 | 主语前 / 并列成分之间 / 逗号后 | I am Mike, **and**... |
| 副词 | 动词前后 / 句首句尾 / 形容词前 | jump **happily** / **very** happy |
| 代词 | 主格作主语 / 宾格作宾语 | **I** can sing. / Mike saw **me**. |

### 变形规则速查

动词→三单（-s/-es），动词→过去式（-ed），动词→现在分词（-ing），名词→复数（-s/-es），形容词→副词（+ly）
