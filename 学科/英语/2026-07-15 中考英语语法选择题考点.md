# 中考英语语法选择题考点（材料笔记）

别名：语法选择十大考点。

> 综合自两份外部来源（YouthStudy 精简笔记 + 初高中知识库教学法）。核心口诀 **人·时·名·非·介·连·比·冠·情·词**。

## 摘要

### 十大考点速查

| 简称 | 考点 | 选项特征 |
|:--:|------|------|
| **人** | 人称代词 | I/me/my/mine/myself 等 |
| **时** | 动词时态/语态 | 动词选项，无 to do |
| **名** | 名词单复数/所有格 | 有 's 或 s' |
| **非** | 非谓语动词 | 有 to do / doing / done |
| **介** | 介词 | in, on, of, with, for 等 |
| **连** | 连词 | and, but, if, because, when 等 |
| **比** | 比较级/最高级 | -er/-est 或 more/most |
| **冠** | 冠词 | a / an / the |
| **情** | 情态动词 | can/must/should/may 等 |
| **词** | 词性转换 | 同词根不同后缀 |

### 解题思路要点

**人称代词**：先判形物代（后跟名词？）→ 再判主格（主语位置）/宾格（动词/介词后）

**动词时态**：先找标志词（yesterday/now/already/tomorrow 等）→ 再看上下文动词保持一致

**非谓语动词**：to do 表目的；-ing 作主语/修饰物；-ed 修饰人；原形在情态动词后
