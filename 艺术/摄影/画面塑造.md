# 画面塑造

别名：画面构成、画面表达。

> 镜头只是工具的一小部分。真正决定画面好不好看的，是摄影师如何运用这些要素。

## 塑造画面的要素

从硬到软，从技术到审美：

### 1. 光线
摄影的本质是"用光作画"。光的方向、质感、色温决定画面的第一印象。
- 方向：顺/侧/45°/逆光 → 不同氛围
- 质感：柔光 vs 硬光 → 不同情绪
- 色温：暖（黄昏/烛光）vs 冷（阴天/荧光）→ 不同基调
- 参见 [光线](<人像光线.md>)

### 2. 曝光
画面的明暗基调。不仅仅是"亮暗刚好"，而是**你想让画面亮还是暗**。
- 高调（明亮轻盈）vs 低调（暗沉厚重）
- 曝光不足/过曝有时候是刻意的风格选择

### 3. 影调
从最黑到最白的过渡分布。决定画面的"气质"：
- **高对比**（黑是黑、白是白，中间少）→ 硬朗、情绪、冲击
- **低对比**（灰度丰富、过渡柔和）→ 柔和、安静、复古
- 一张照片的影调分布，决定了它是"锐利的"还是"温柔的"

### 4. 色彩
颜色本身就在说话：
- **色相** — 红/黄暖，蓝/绿冷，互补色搭配产生张力
- **饱和度** — 高饱和热烈，低饱和安静
- **色调统一** — 一组照片保持统一色调，比单张好看更重要
- 黑白——去掉了色彩干扰，逼观众看光影、形状和内容

### 5. 构图
元素在画面里的摆放方式。基础框架：
- **三分法** — 把主体放 1/3 线上
- **引导线** — 用线条把视线引向主体
- **框架构图** — 用窗/门/树枝做画中画
- **留白** — 空的地方和满的地方一样重要
- **对称/均衡** — 稳定感 vs 动态感

### 6. 内容/故事
以上所有要素最终服务于一件事：**观众看了这张照片在想什么。**
- 有人在做什么（动作）
- 那个瞬间发生了什么（事件）
- 这个场景有什么情绪（氛围）
- 照片之外还有什么故事（想象空间）

### 7. 透视（焦段的选择）
焦段决定空间关系，是最后一个要决定的——在以上都考虑清楚后，才选广角/标准/长焦。参照三个笔记：
- [广角 — 建筑师思维](<广角镜头.md>)
- [标准 — 叙述者思维](<标准镜头.md>)
- [长焦 — 猎人思维](<长焦镜头.md>)

## 要素之间的关系

这些要素不是独立起作用的，是互相影响的：

```
光线 → 曝光 → 影调
                         ↘
             构图 + 色彩 + 内容 = 最终画面
                         ↗
              焦段 → 透视
```

- 光线的方向影响构图的选择
- 影调的偏好影响曝光决策
- 内容决定用什么焦段，不是反过来

## 镜头的定位

**镜头只是其中一小点。**

广角的冲击力、长焦的压缩感——这些只是"镜头效果"。真正让一张照片有力量的是光线怎么布置、颜色怎么搭配、构图怎么安排、捕捉到了什么瞬间。

- 新手阶段：注意力在镜头上（"我要买什么镜头"）
- 进阶阶段：注意力在这些要素上（"我要怎么塑造画面"）

> 不要把器材的乐趣当成摄影的乐趣。
