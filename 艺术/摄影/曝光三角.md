# 曝光三角

别名：exposure triangle、曝光铁三角。

> 光圈、快门、ISO 三者共同决定照片的曝光量。核心心法：**曝光不变，画面变**——相同曝光量下不同参数组合产生完全不同的画面效果。

## 三个参数一览

| 参数 | 控制什么 | 数值规律 | 对画面最主要的影响 |
|------|---------|---------|----------------|
| **光圈** Aperture | 进光孔大小 | f/数值越小 → 孔越大 → 进光越多 | **景深** — 大光圈虚化背景，小光圈前后清晰 |
| **快门速度** Shutter | 感光时长 | 分母越小 → 速度越慢 → 进光越多 | **运动表现** — 高速凝固动作，低速记录轨迹 |
| **ISO** 感光度 | 传感器敏感度 | 数值越高 → 越敏感 → 画面越亮 | **噪点** — 高 ISO 亮但脏，低 ISO 暗但干净 |

> **一句话口诀**：光圈管景深，快门管动态模糊，ISO 管画质。
> 三个都管亮度，但各有一张别人替代不了的名片——这就是为什么调整要有优先级：先定要的景深/动态，再补亮度，ISO 最后动（动了就伤画质）。

## 拍摄决策优先级

实际操作中的先后顺序：

```
① 光圈先决 → ② 快门底线 → ③ ISO 最后手段
```

### ① 光圈先决

先决定要什么景深：

- 想要背景虚化突出主体 → **大光圈**（f/2.8、f/4）
- 想要前后都清晰交代环境 → **小光圈**（f/8、f/11）

### ② 快门底线

再保证不糊片：

- 拍人最好不低于 **1/125-1/200s**
- **安全快门公式** ≈ 1/焦段（50mm → 1/50s，135mm → 1/125s）
- 低于安全快门 → 手抖糊片风险大增
- 低于 1/60s → 手持基本不稳，上三脚架

### ③ ISO 最后手段

光圈和快门都定好后，曝光还不够，才拉 ISO：

- 拉 ISO 有代价（噪点），所以能靠补光就别拉 ISO
- 知道底线在哪后，日常可用 **自动 ISO 设范围上限**（省一个变量）

## 6D 实测数据

通过自己的噪点测试（室内暗光，ISO 从 100 逐档测到 6400）：

| ISO 范围 | 画质表现 |
|---------|---------|
| 100-800 | 干净，可用 |
| **1250** | **开始变脏——个人容忍上限** |
| 1600+ | 颗粒感明显，非必要不用 |

ISO 效果也看机身——传感器尺寸 + 代际影响巨大。同样是全幅，新机身 ISO 3200 可能比老机身的 400 还干净。6D（2012）和新机差了十几年，不要拿自己的标准去套别人的参数。

## 核心心法

> 同一场景，f/5.6 + 1/125s + ISO 200 和 f/2.8 + 1/500s + ISO 200，**曝光量一样，画面完全不一样**。
> 前者景深深、后者虚化强——这就是要建立的感觉：**不是背参数，是知道每个参数在画面上留下什么痕迹。**

## 补光 vs 拉 ISO 的决策

| 场景 | 策略 | 理由 |
|------|------|------|
| 摆拍、人像、产品 | **补光** | 拍好比拍到更重要 |
| 纪实、抓拍、街头 | **拉 ISO** | 拍到比拍好更重要 |

## 曝光补偿（±EV）

相机测光会把场景“平均成中间灰”。遇到极端场景，测光会被骗，需要手动补偿：

| 场景 | 相机误判 | 补偿 |
|------|---------|------|
| 白色/亮场景（雪地、白墙、穿白衣） | 自动测光偏暗（想把白色压成灰） | **+EV**（提亮） |
| 黑色/暗场景（黑背景、穿黑衣） | 自动测光偏亮（想把黑色提成灰） | **-EV**（压暗） |

- **直方图是判断依据**：峰值偏左被压 → +EV；偏右溢出 → -EV（配合 [直方图](<直方图.md>)）
- 用 A/S/P 档时用 ±EV 快捷调曝光；M 档则直接调参数，不需补偿
- 理解原理后，也可以用曝光补偿做**主观的向左/向右曝光**（影调控制）

## 噪点的另一面

高 ISO 噪点不一定是缺陷——工具的“缺陷”可以是视觉语言：

- **深瀬昌久《鴉》** — 粗颗粒表达孤独压抑
- **森山大道** — 高反差噪点做街拍风格
- 也可模仿胶片颗粒感、电影质感

## 七日训练计划

每天 15-20 分钟，M 档。前 3 天 ISO 锁 200。

| 天 | 练什么 | 操作 |
|----|--------|------|
| 1 | 光圈阶梯 | 同一场景，f/3.5→f/5.6→f/8→f/11→f/16→f/22，只看景深变化 |
| 2 | 快门阶梯 | 拍流水/车流，1/1000→1/500→1/250→1/60→1/15→1”，看凝固 vs 拖影 |
| 3 | ISO 噪点测试 | 暗光环境，ISO 100→200→400→800→1600→3200→6400，找个人容忍上限 |
| 4 | 光圈优先日 | A/Av 档感受，15 分钟后切 M 档重现 |
| 5 | 快门优先日 | S/Tv 档感受，15 分钟后切 M 档重现 |
| 6 | 曝光补偿 | 高反差场景（窗边逆光、白墙、暗色背景）± 补偿 |
| 7 | **综合检验** | 同一场景拍三张：浅景深 / 冻结动作 / 最低噪点 |

**检验标准**：对着任何一个场景，说得出一句“我用 f/X，1/X 秒，ISO X，因为我想让画面……”
