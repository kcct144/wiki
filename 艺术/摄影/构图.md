# 构图

别名：photographic composition、构图方法。

> 构图不是目的，是**表达主题的手段**。

## 构图的意义

- 任何构图都建立在**你想表达的主题 + 你阐述的内容**之上，不是"为了构图而构图"
- 要根据**想表现的内容**去分配合适的构图
- **主次顺序要明确** — 画面里什么重要、什么次要，先想清楚

> 先有内容，再有构图。构图服务于内容，不是内容迁就构图。

## 横平竖直

照片中有**明显参照物**时，必须做到横平竖直：
- 地平线、海平线、建筑、门框、窗沿、立柱等
- **不能为了某种构图形式把照片拍得东倒西歪** —— 这是构图大忌

> 竖的东西要竖、横的东西要横。除非是刻意的"水平线倾斜"表达，否则拍歪就是失误，不是风格。

## 人像不要裁关节

人物比例怪、残缺、"像截肢"，多是因为**裁切位置选在了关节处**（肘、腕、膝、踝），或裁在错误的肢体部位。

### 安全裁切位置

| 景别 | 裁切到哪 | 避开 |
|------|---------|------|
| **特写（大头）** | 肩膀线 | 脖子中段 |
| **胸像** | 胸部下沿（胸口） | 胸部中间 |
| **半身** | 腰 / 肚脐以上 | 肘、腕 |
| **七分身** | 大腿中部（膝上） | 膝盖 |
| **九分身** | 小腿中部 | 脚踝 |
| **全身** | 完整，脚在画面内 | 脚踝/脚掌截断 |

> 核心原则：**不要裁在关节，要裁在肢体中段**。裁在关节像"截肢"；裁在肢体中段才自然。真拿不准，就放宽景别（宁可全身也别裁半截）。

## 留白（负空间）

**留白** = 主体之外的"空"区域（纯色背景、天空、墙面、大面积虚化区）。它不是"留空"，是"留情绪"——服务于内容和主题，不为留白而留白。

### 留白的作用

| 作用 | 说明 |
|------|------|
| **呼吸感** | 画面不闷，有透气处 |
| **突出主体** | 靠"空"与"实"的对比让主体更聚焦 |
| **情绪意境** | 大留白 → 孤独、安静、辽阔、空旷、高级 |
| **引导视线** | 顺着留白方向延伸想象 |

### 留白的位置（经典讲究）

1. **头顶留白** — 头顶上方留空间，别"顶天立地"
2. **视线方向留白（最重要）** — **人物看哪边，哪边多留白**；视线朝向的空间应大于背后空间，否则憋闷有"撞墙感"
3. **运动/动作方向留白** — 人物往哪动，哪边留白，给动作"留出路"

> 核心原则：**留白要顺着视线/运动方向**。留白方向留错（人物背后留一堆空），视觉会堵。留白也不是越多越好——多与少取决于想表达的情绪。

### 视线留白：单张是美学，系列是叙事

同一个视线留白，在不同语境下是两种功能：

| | 单张照片 | 系列照片 |
|---|---------|---------|
| 功能 | **美学** — 延伸感、想象空间、好看 | **叙事钩子** — 埋下一个问题 |
| 观众反应 | "构图舒服" | "主角在看什么？" |
| 它做的事 | 完成画面 | 留下悬念，等待下一张接住 |

系列里，视线留白向观众发出"前方有东西"的信号，**下一张恰好可以交代主角在看什么**——这就是电影剪辑里的"视线匹配剪辑"（eyeline match），只是用"下一张"代替了"剪辑"。也呼应了"内容靠系列累积叙事"（见标准镜头/川島小鳥）。

> 判断用哪种：只出一张 → 留白是装饰；拍系列 → 留白可以当叙事的接力棒。

### 反向留白（情绪化·压抑）

与视线引导留白相反：**人眼前方堵死（视线方向无空间甚至被遮挡），后方留白**。

| | 视线留白（正向） | 反向留白 |
|---|---------------|---------|
| 人前 | 有空间，视线有去处 | **堵死**（边/遮挡物挡住） |
| 人后 | 少 | 多 |
| 视觉感受 | 开阔、延伸、舒服 | **受阻、压抑** |
| 情绪 | 想象、宁静、开阔 | 情绪化、心理张力、封闭 |

> 同一个"前方堵住"，两种读法：中性人像里是**失误**（视觉堵住观感差）；情绪片里是**刻意**（正是要的压抑感）。想拍舒服用正向留白，想拍压抑就反向堵死——用构图代替影调表达情绪。
> **反向留白最对口的情绪**：阴郁、忧郁、迷茫——共同点是"看不清前路、被困住"，和"眼前堵死"同构。人物看天看海（正向）表达向往开阔；被堵着看着画面边缘（反向）表达迷惘压抑。

## 构图形式：点线面

构图形式可以从**点、线、面**来拆。

> 说明：**留白构图**已在前文单独展开（见上"留白"节），这里不重复。

### 点构图

**中心点构图** — 主体放画面中心：
- 主体足够出彩就可以（画面一眼聚焦到中心）
- 主体不够出彩就显得平淡（中心位不提供额外视觉张力）

> 中心构图很"稳"，但**不帮主体加分**——它只是把观众目光放到中间，能不能吸引人全看主体本身。主体出彩才用，否则会显平淡。

### 对比构图

让画面中的元素形成对比，制造视觉张力与主次：

| 对比类型 | 例子 | 效果 |
|---------|------|------|
| **大小对比** | 大与小 | 通过大小反差突出某一方 |
| **色彩对比** | 冷暖、互补色 | 色彩反差让主体跳出背景 |
| **明暗对比** | 亮与暗 | 亮部抓眼，暗部衬托 |
| **动静对比** | 静物与运动 | 动态与静态互相衬托 |

> 对比的本质是"反差点吸引注意力"——有了对比，观众的目光自然落在被突出的一方，主次关系自动建立。这比单纯的主体居中更有张力。

### 对称构图

画面左右（或上下）对称，以中心轴为镜面。

- **效果**：庄重、稳定、正式、仪式感、平衡
- **适用**：建筑、倒影、中心对称场景、正式/端庄人像
- **注意**：对称很"稳"，但也容易显呆板、单一——需要主体或内容撑住，否则画面死板

> 对称构图自带庄重感和秩序感，但**稳 ≠ 好看**——它和中心构图一样，形式不替内容加分。对称失衡一点反而有张力，但要慎用。

### 框架构图

用画面中的元素（门框、窗户、拱门、树枝、栏杆…）框住主体：

- **集中视线** — 把观众目光框进框架内，主体被自动聚焦
- **天然减法** — 杂乱的画面被框架挡住，不用刻意虚化
- **增加层次** — 框架作前景，画面有前后纵深感
- **窥视感/故事感** — 像透过门/窗看人，有"偷看"的叙事氛围

> 框架构图是把"杂乱变秩序"的好手段——找一个天然框（门/窗/拱），既做减法又加层次。呼应广角的前景用法：框架本身可以靠近镜头当夸张前景。

### 面构图

**三角构图** — 用画面元素构成三角形布局：

- **稳定感** — 三角形是最稳固的形状，画面有重心、均衡
- **结构感** — 三点分布让画面有骨架，不乱
- **引导视线** — 三角形的边/顶点引导目光走向
- **常见形态**：正三角（稳定）、倒三角（不稳定、动感）、斜三角（灵活）
- **人像应用**：头部 + 双肩自然成三角；多个人物/元素分布成三角

> 三角构图是"面"的经典——用三点撑起画面的结构，稳而不死板。是群像、多人构图的主心骨。

### 前景构图

把一些东西放到前景（靠近镜头），三个作用：

- **引导视线** — 前景的线条/形态把目光引向主体
- **挡住不想要的元素** — 用前景遮挡画面里多余/杂乱的部分
- **突出氛围** — 前景渲染环境氛围、季节感、空间感

> 前景构图与框架构图、广角前景用法同源：**用"离镜头近的东西"来影响画面**。近景虚化/夸张，主体在清晰的中景，前后呼应出纵深和氛围。

### 三分线构图（三分法）

把画面横竖各分成三等份 → 四条分割线 + 四个交点：

- **主体放在分割线上**（或交点上）→ 有突出效果，不呆板
- 分割线常放：地平线、海平线、人物
- **交点**（三分点）是视觉重心，放主体很抓眼
- 最常用、最普适的构图——**先三分，再玩其他**

> 三分法是"万用安全牌"：把主体放线/交点上，画面天然平衡又不呆板。几乎所有构图都建立在"先三分"的基础上。

### 线构图

**对角线构图** — 利用画面中的对角线，让主体或元素沿对角线分布：

- **动感** — 斜线打破横平竖直的平稳，画面更活泼、有张力
- **延伸感** — 对角线让视线沿斜向延伸，空间感强
- **适用**：运动、流水、道路、桥梁、肢体线条
- **结合**：S 型、引导线等也是"线构图"的变体——用线条引导目光

> 线构图的核心：**画面里的线是"引导视线"的路径**。对角线最动感，S 型最流畅，直线最直接——选哪条线，决定观众的目光怎么走。

### 引导点构图

用画面中的元素把观众目光**引导到一个焦点（引导点）**上：

- **线的引导** — 线条、汇聚线把视线引向主体
- **视线引导** — 人物看向的方向把观众目光带过去
- **元素引导** — 前景/亮度/对比把注意力引到某一点
- **效果**：让焦点成为画面的"落点"，主次更清晰

> 引导点构图是"安排视线"的集大成——线、前景、视线、明暗都能当"引导工具"，最终把目光送到你要的那一点上。与线构图、前景构图、对比构图互为配合。

### 重复构图

利用画面中重复出现的元素（相同/相似的形状、线条、图案）构成规律：

- **节奏感 / 韵律感** — 重复制造规律的视觉节奏
- **秩序感 / 形式感** — 重复让画面有结构、有美感
- **破重复（关键）** — 在重复中放一个"不一样"的元素 → 它是全场最抓眼的点
- **适用**：建筑阵列、栏杆、窗户、书脊排列、人群、几何图案

> 重复构图是"先建立规律，再打破规律"的艺术——重复本身好看，但**打破重复的那一点，才是观众目光的落点**。常和对比构图配合。

## 人像构图

人像构图的专项规则（区别于通用构图形式）。

### 地平线不要穿过头部

**地平线（海平线/其他水平线）不能从头部、脖子、眼睛处穿过。**

- 原因：水平线是画面里最"重"的线，从头颈穿过会：
  1. **视觉上把人物"劈开"** — 头被拦腰切断，像"人头后长一条线"
  2. **抢注意力** — 线恰好落在该聚焦的脸部，和五官抢戏
- 正确：让地平线落在**人物上方或下方**，避开头颈和眼睛这条"重线区"

### 胯骨不能裁切

**人的胯骨（髋部）不能裁切**——它是身体的重要"转折关节"，从这儿裁切会把人物视觉上"截成两截"。

- 呼应"不裁关节"原则：裁在关节像"截肢/断腰"
- 半身/中景时，裁切位置应选在**腰上（胸下）**或**大腿中部**，避开胯骨这条线
- 宁可景别放宽一点，也别卡在胯骨/髋部

> 人像裁切的通用口诀：**避开一切关节和"转折点"**（肘/腕/膝/踝/胯），裁在肢体中段最自然。
