# 景深

别名：depth of field、DOF。

> 景深（Depth of Field）指照片中物体前后清晰的范围。控制景深是摄影最基础也最常用的表达手段。

## 影响景深的三个因素

```
光圈（最主要） > 焦段 > 距离
```

| 因素 | 规律 | 应用场景 |
|------|---------|---------|
| **光圈** | 越大（f/数值越小）→ 景深越浅 | 人像大光圈虚化背景 |
| **焦段** | 越长 → 景深越浅 | 长焦端自然压缩景深 |
| **距离** | 离被摄体越近 → 景深越浅 | 微距 / 特写 |

三个因素可以叠加。想要最浅景深：**最大光圈 + 最长焦段 + 最近对焦距离**。

## 景深的用途

- **浅景深（大光圈）** → 背景虚化 → 突出主体。最常用的减法构图手段
- **深景深（小光圈）** → 前后都清晰 → 环境人像或风光，交代主体和背景的关系

> 不是越虚越好。人文纪实常用 f/5.6：主体突出，背景保留层次感。

## 光圈实用经验

### 不要开到最大

最大光圈容易跑焦（尤其大光圈下对焦精度要求极高）、边缘画质下降。**收半档到一档更稳。**

**为什么大光圈容易跑焦：**

- **景深太浅** — f/1.4 的景深可能只有几毫米，对焦点稍偏（靠前/靠后），眼睛虚了耳朵实的，后期救不回失焦
- **对焦误差被放大** — 单反对焦系统（尤其老机 6D）精度有限，大光圈把这个误差放大到肉眼可见
- 反过来：最大光圈本来就小的镜头（如 f/3.5-5.6）跑焦风险天然低——这是它“不致命”的另一个原因

### 最佳画质光圈

最大光圈缩 2-3 档是镜头最锐的光圈范围。

以 **28-135mm f/3.5-5.6** 为例：

| 焦段端 | 最大光圈 | 最佳画质光圈 |
|--------|---------|------------|
| 28mm 广角端 | f/3.5 | **f/5.6 - f/8** |
| 135mm 长焦端 | f/5.6 | **f/8 - f/11** |

### 常见场景的光圈选择

| 场景 | 建议光圈 | 理由 |
|------|---------|------|
| 人像（单人或半身） | f/2.8 - f/4 | 虚化背景突出主体 |
| 人文纪实 | f/5.6 | 主体突出 + 背景保留层次 |
| 环境人像 | f/5.6 - f/8 | 人物和背景都清晰 |
| 风光 / 建筑 | f/8 - f/11 | 从近到远全局清晰 |
| 产品 / 商业 | f/8 - f/11 | 全局锐利 |
| 合照（多人） | f/5.6 - f/8 | 前后排都要清晰 |

### 光圈优先（A/Av 档）

适合日常人像、静物——控景深是主要诉求，快门交给相机自动匹配。用熟了再切 M 档。
