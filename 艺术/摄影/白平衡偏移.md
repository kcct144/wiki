# 白平衡偏移

别名：白平衡调整、white balance shift。

> 白平衡让相机知道"什么是白色"。白平衡偏移则是**故意让白色不准**，制造统一的色调倾向。

## 四个偏移方向

佳能白平衡偏移网格：

```
            绿 (G)
             ↑
   蓝 (B) ← 中 → 琥珀 (A)
             ↓
           品红 (M)
```

| 方向 | 效果 | 适用场景 |
|------|------|---------|
| **A（琥珀）** | 暖黄 | 日落、烛光、复古、温暖氛围 |
| **B（蓝）** | 冷蓝 | 清冷、阴天、夜景、科技感 |
| **G（绿）** | 偏绿 | 复古胶片、荧光灯环境 |
| **M（品红）** | 紫红 | 梦幻、日落氛围、花卉 |

可组合移动，如 A2G2 = 暖中带绿（复古感）。

## 白平衡偏移的作用

1. **渲染画面氛围** — 色温决定照片的"温度感"
2. **控制颜色偏移程度** — 偏多少、往哪个方向偏

## 常见风格的白平衡倾向

| 风格 | 偏移方向 | 感觉 |
|------|---------|------|
| 清冷古风 | B（冷蓝） | 清冷、克制 |
| 复古胶片 | A+G（暖+绿） | 旧照片、年代感 |
| 日系清新 | B+G 或 A+M | 柔和、洁净或温暖 |
| 情绪片 | B+M 或 A+R（红） | 戏剧感、情绪浓烈 |
