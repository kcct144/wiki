# 直方图

别名：曝光直方图、histogram。

> 判断曝光/影调的依据，要**看直方图而不是肉眼**。

## 为什么看直方图，而不是肉眼

肉眼看照片判断曝光有三大根本盲区：

1. **肉眼和屏幕会被环境欺骗** — 屏幕观感取决于周围光线。白天亮房间觉得"刚好"，晚上关灯看同一张就"过亮"。直方图是像素的实际亮度，和你在哪看无关
2. **肉眼会自动"增益"（适应）** — 大脑会自动提亮暗部、脑补过曝区域，你觉得"还行"其实已经死了。直方图如实反映
3. **肉眼看不清是否"溢出"** — 过曝欠曝的本质是**像素被挤出动态范围**（死白/死黑），一旦裁切所有像素变成同一个颜色，屏幕上看起来全都一样。直方图直接告诉你山峰有没有顶到边缘

> 肉眼看的是"这张照片此刻看起来怎样"（主观、随环境漂移）；直方图看的是"像素实际亮度的分布"（客观、固定）。判断曝光就是判断"有没有细节被裁切"，这是数据问题。

## 取景框 · 屏幕 · 照片为什么不一样

三者显示的是**三种不同加工程度的画面**：

```
取景框 → 屏幕预览 → raw(原料) → 后期成片
 现场光    加工过的成品      未加工
```

| | 取景框 | 屏幕 | raw 照片 |
|---|--------|------|---------|
| 看到的是 | 现场光 | 相机加工的成品预览 | 未加工原料 |
| 光圈状态 | 全开（偏亮，方便取景） | 按拍摄设置模拟 | 按拍摄设置 |
| 是否含后期风格 | 否 | 是（风格模式） | 否 |
| 保真度 | 最"现场" | 最"好看"但不准 | 最"原始" |

- **取景框** — 透过镜头的真实光线，光圈全开所以特别亮；不模拟快门/白平衡/ISO/后期。看到的是"现场"，不是"照片"
- **屏幕** — 相机按风格模式（标准/人像/风光、饱和度、对比）渲染的 JPEG 预览，偏鲜艳好看；屏幕硬件本身分辨率低、动态范围小、亮度随环境漂移
- **raw** — 传感器原始数据，未套风格，更灰更平更淡，但动态范围更大、细节保留更多，是后期发挥的空间

> 一句话：**取景框骗你"太亮"，屏幕骗你"太好看"，raw 才是一张白纸等你来画。** 这也解释了为什么判断曝光要看直方图——取景框和屏幕都经过了不同程度的"美化/模拟"，只有数据是诚实的。

## 横轴与纵轴

```
纵轴（像素多少）
  ↑
  │      ╭───╮
  │     ╭╯   ╰╮
  │    ╭╯     ╰╮
  │   ╭╯       ╰╮
  └──╰─────────╯──→
      暗          亮
     （横轴：亮度，左暗右亮）
```

- **横轴** = 亮度（左暗 → 右亮）
- **纵轴** = 像素数量（细节信息的多少）

## 山峰位置判断曝光

| 山峰位置 | 含义 | 潜在问题 |
|---------|------|---------|
| **偏右** | 亮调（高调） | 顶到最右 = 过曝/死白 |
| **偏左** | 暗调（低调） | 顶到最左 = 欠曝/死黑 |
| **居中** | 中间调，曝光正常 | — |

> 山峰位置看**整体调子**；是否"顶到边缘"才看是否**溢出**。一张好的照片不只一个山峰——暗部有细节、亮部有内容才丰富。

## 修图工具里的直方图

- **Photoshop（PS）** — 面板/色阶/曲线里的直方图
- **ACR（Camera Raw）** — 读 raw 时的直方图，结合五大基准调整

## 五大基准

调整的五个锚点：**黑色 Black · 阴影 Shadows · 曝光 Exposure · 高光 Highlights · 白色 White**

结合五大基准调片的三个用途：
- **a. 调细节** — 让曝光正常，暗部不欠、亮部不过
- **b. 塑造光影层次** — 拉开明暗，制造立体感/氛围
- **c. 调整色彩** — 通过明度分布间接影响色调表现

## 直方图形状 = 照片风格

| 形状 | 特征 | 典型风格 |
|------|------|---------|
| **正常型** | 无强烈反差，光比小，像素分布均匀 | 常规照片 |
| **单峰左移** | 暗部集中，像素堆在左边 | 夜景、夕阳、黑背景 |
| **单峰右移** | 亮部集中，像素堆在右边 | 小清新、日系 |
| **U 型** | 两边高中间低，反差极大 | 剪影 |
