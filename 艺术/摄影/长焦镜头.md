# 长焦镜头

别名：telephoto lens、135mm 镜头。

> 基于 135mm（全幅）使用经验。装备：佳能 6D + EF 28-135mm f/3.5-5.6 IS USM 长焦端。

## 长焦 vs 广角

| | 广角（28mm） | 长焦（135mm） |
|---|---|---|
| **视角** | 宽，框得多 | 窄，框得少 |
| **透视** | 最强，近大远小夸张 | **最弱，空间被压缩** |
| **主体关系** | 被迫靠近，主动创造 | 可以远离，安静捕捉 |
| **思维** | 建筑师 | 猎人 |

## 三个核心特性

### 1. 空间压缩
长焦最反直觉但最有用的效果——前后物体看起来被"压"在一起了。
- 广角让你感觉"人和背景离得很远"
- 长焦让你感觉**"人和背景贴在一起"**
- 实用：背景里的树/山/建筑被拉到人物身后，产生"人和环境融为一体"的感觉

### 2. 减少元素
- 视角窄 → 框进来的东西少 → 天然做减法
- **背景杂乱时，长焦比广角好控制得多**
- 不需要像广角那样主动安排画面，"框住想拍的，其他裁掉就行"

### 3. 放大细节
- 拍半身/特写，主体充满画面，细节更丰富
- 远距离捕捉被摄者最自然的状态（不影响对方）

## 135mm 端注意事项

| 注意点 | 说明 |
|-------|------|
| **安全快门** | 至少 **1/125s-1/160s**，不然手抖糊片（安全快门 = 1/焦段） |
| **最大光圈 f/5.6** | 偏小，室内或暗光下噪点可能拉高 |
| **虚化能力** | f/5.6 在 135mm 半身/特写仍有一定虚化，但比不上专门的 85mm f/1.8 或 70-200 f/2.8 |
| **需要退后** | 拍半身照可能要退好几米，室内施展不开 |

## 用法

### 半身/特写人像
长焦天然显脸瘦（透视压缩效果），面部五官比例舒服，是最"安全"的人像焦段。人脸放画面中不会畸变。

### 背景压缩
找远处好看的背景（灯光、树叶、建筑），用长焦拉到人物身后，让背景和人物融为一体，画面更饱满。

### 抓拍/街拍/不打扰拍摄
离得远，不影响被摄者，捕捉最自然的状态。这是长焦独有的能力——远远地拍，对方根本不知道你在拍。
- **拍小孩** — 近了反而不自然，长焦远距离拍到最真实的表情和动作
- **拍动物** — 宠物/街猫/鸟，靠近会惊跑，长焦安全距离
- **拍陌生人/街拍** — 不影响对方，捕捉真实的生活瞬间
- 长焦出片 = 发现和捕捉（猎人思维），和广角的主动创造（建筑师思维）完全不同

### 拍日落/月亮
长焦能把太阳拍得很大很突出。原理：视角窄 + 空间压缩，太阳在画面中的占比远大于广角。135mm 端拍日落，太阳大小感比 28mm 端大好几倍。

### 古风人像
古风摄影很喜欢用长焦。三个原因：
- **背景压缩** — 把远处的山、树、古建筑"拉"到人物身后，景物和人物融合成一张画卷
- **远距离抓拍** — 古风动作（回眸、甩袖、转身）适合在远处连拍捕捉最自然的一瞬
- **空间扁平化** — 古风追求像国画一样的二维画面感，长焦的压缩效果正好实现。光影也不宜太立体太硬，柔和均匀的光配合扁平透视，制造"画中人"的感觉

## 快速决策

| 条件 | 选择 |
|------|------|
| 只想突出人物本身 | → 长焦 |
| 背景杂乱，无关元素多 | → **长焦（这是它的强项）** |
| 想安静抓拍自然状态 | → 长焦 |
| 想显脸瘦、拍舒服的半身/特写 | → 长焦 |
| 想交代环境、制造纵深感 | → 广角 |
| 小空间室内 | → 广角（长焦退不开） |
| 照片太平没层次 | → 广角 |
