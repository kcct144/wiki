# 机位

别名：拍摄机位、camera position。

> 机位 = 相机的位置，即相机与模特的三维位置关系。

## 三个维度

```
机位 = 机位高度 × 机位角度 × 机位距离
```

### 机位高度

| 高度 | 效果 | 适用场景 |
|------|------|---------|
| **平视机位** | 相机与取景框中心对焦点持平，自然、平等、亲切 | 纪实、标准人像、日常记录 |
| **低机位** | 主体显高大、有力量、气场强 | 全身人像、建筑、穿搭 |
| **高机位** | 主体显小、柔弱、可爱 | 美食、产品、女生躺姿 |

### 平视机位的优势

平视机位是最接近人眼观看习惯的视角：

- **五官真实** — 没有透视畸变，五官比例自然，不像自己都不行
- **视角天然** — 和人眼看到的画面差不多，观众不需要"适应"画面
- **情绪共鸣** — 平视让观众感觉"我和你一样"，更容易产生共情
- **不介入** — 低机位先传达了"ta有力量"，高机位先传达了"ta很柔弱"，这些"机位的态度"在被摄者的情绪传递到观众之前，先加了一层滤镜。平视不介入，情绪直达

### 平视的微妙偏移

平视不是非得"完全水平"。在平视附近微调高度，效果完全不同：

| 位置 | 效果 | 适用场景 | 对应风格 |
|------|------|---------|---------|
| **严格平视** | 最真实、最中立 | 证件照、纪实、标准肖像 | 纪实、真实 |
| **略低一点**（微仰） | 有高级感，被摄者多了几分从容和自信，但又不会像低机位那样有压迫感 | 时尚人像、商业肖像、需要"精致感"的人像 | **欧美风** — 仰视把人物抬高，显得高不可攀、有距离感，符合时尚杂志那种"冷、独立、难以接近"的气质 |
| **略高一点**（微俯） | 被摄者显得柔和乖巧，但又不像高机位那样有距离感 | 日常记录、女生半身、探店打卡 | **甜美风** — 俯视让被摄者显小、显嫩，天然唤起保护欲和亲近感 |

> 同一对方向，两种气质。微仰 = 抬高 = 距离感（欧美冷感），微俯 = 压低 = 亲近感（甜美可爱）。

> 低机位给人"力量感"，但微仰给人"高级感"。差几厘米，感受完全不同。
> 平视是范围，不是一个点。**±15°** 以内都算平视范围（超过则进入低/高机位范畴）。在这个范围内微调，是进阶控制感的关键。

### 必须用平视的场景

- **证件照** — 必须平视，低/高机位会导致五官变形，不符合身份识别标准
- **名人肖像** — 不是"仰望"也不是"俯瞰"，是面对面，平等中有尊重
- **人文纪实** — 平视把摄影师放在和被摄者相同的高度，记录的是真实的人，不是被俯视的"研究对象"

### 机位角度

| 角度 | 效果 | 适用场景 |
|------|------|---------|
| **正面** | 直接、有冲击力、互动感强 | 肖像、正式照 |
| **侧面** | 轮廓线条突出，叙事感 | 剪影、情绪片、侧颜 |
| **背面** | 神秘、代入感、环境感 | 环境人像、背影 |

### 机位距离（取景范围）

| 景别 | 范围 | 效果 |
|------|------|------|
| **特写** | 局部（眼/手/嘴） | 极致细节，情绪放大 |
| **近景** | 胸部以上 | 表情细节，情感交流 |
| **中景** | 半身或膝盖以上 | 最常用，兼顾人物和环境 |
| **全景** | 全身 | 人和环境都有 |
| **远景** | 人在环境中占很小比例 | 环境氛围 > 人物 |

> 从远景到特写：**环境 → 人物 → 小细节**，是一个逐渐聚焦的过程。远景说"这是在哪"，中景说"这个人是谁"，特写说"这个瞬间的情绪是什么"。

## 三个维度的组合

一个机位是三个维度的交叉结果。例如：

> **低机位 + 正面 + 近景** → 有冲击力的肖像，脸有压迫感
> **平视 + 侧面 + 中景** → 自然叙事，像朋友在聊天
> **高机位 + 正面 + 全景** → 人物显小，环境主导
> **平视 + 正面/侧面 + 近景/特写** → 突出人物情绪，观众注意力集中在表情上

## 机位与表达意图

选择的本质是**让观众看什么**。

| 想突出 | 机位组合 |
|--------|---------|
| 人物情绪 | **平视 + 近景/特写** — 平视不带态度，近景/特写把脸拉近，情绪没有干扰 |
| 力量感 | **低机位 + 近景/中景** — 仰视给你力量，近景让你感受到压迫感 |
| 环境氛围 | **高机位/平视 + 全景/远景** — 人物让位给环境 |
| 人物与环境的关系 | **平视 + 中景** — 人和环境都有，最均衡 |

> 距离决定了观众能读到多少信息。情绪在脸上，离远了注意力自然被环境拉走——这和高度无关，是景别在说话。

### 平视的局限

**平视不适合远景/全景**——因为平视的视角就是人天天看到的视角，缺乏新鲜感。远景/全景框进来的环境信息很多，如果还用一个"天天看"的角度，画面很容易平平无奇。

补救方式：远景/全景时换低机位或高机位，用角度制造视觉冲击力。

## 人像三要素

> **人像三要素：模特，模特，模特。** — 人像的成败，最决定性的因素是被摄者本人，不是镜头、不是机位、不是后期。

机位无法改变模特，但能**扬长避短**——用角度规避五官的缺点，放大优点。

### 用机位规避五官缺点

| 想规避的缺点 | 机位手法 | 原理 |
|-------------|---------|------|
| **脸大 / 脸圆** | 微俯（机位略高）+ 四分之三脸 | 俯视让脸纵向收窄，显得小；四分之三脸弱化脸部宽度 |
| **下巴肉 / 双下巴** | 微俯 + 微微低头 | 俯视收下巴，肉感被角度吃掉；避免大角度仰视（会放大） |
| **鼻子大** | 侧面 / 四分之三脸 | 正面是鼻子的"最大投影"，转侧让鼻子退到轮廓里 |
| **左右不对称** | 四分之三脸，选好看的一侧 | 把"有优势的一侧"对着镜头 |
| **颧骨高 / 脸型硬** | 正面 + 微俯，或稍侧 | 避免纯侧面暴露颧骨高度；俯视柔化脸部轮廓 |
| **额头大 / 发际线高** | 微俯 + 刘海/手部遮挡 | 俯视让额头占比变小，配合遮挡 |
| **眼睛小** | 相机拿近（近景）+ 俯拍 | 俯视强调上半脸（近大远小）；机位在上方模特抬头看镜头，眼睛自然睁大 |
| **嘴巴小** | 相机拿近（近景），**别俯拍**；用微仰 + 放松唇形 | 嘴巴在下半脸，俯视会把它压得更小；微仰强调下半脸，近景让嘴占画面更多 |

**通用思路**：
- 正脸最"暴露"五官，侧脸最"保护"五官 → 五官有缺陷时多用侧面/四分之三脸
- 高度是"扬长避短"的杠杆：想显脸小就微俯，想突出下颌线就微仰（但下巴有肉慎仰）
- 特写放大部分缺点 → 规避五官问题时，用中景/近景，别用特写硬刚

### 特例：凸嘴（嘴部前突）

凸嘴是**纯侧面最明显**（90° 侧脸直接暴露嘴部前突），所以首要原则是**避开纯侧面**：

1. **四分之三脸 / 正面为主** — 转侧到四分之三就弱化了前突，正面则几乎看不出来
2. **微仰 + 收下巴低头** — 这是凸嘴最有效的经典组合：机位略低（微仰），同时让模特**微微低头收下巴**。下巴向前伸，和前突的嘴"对齐"，侧面线条反而更均衡
   - 关键：光仰不低头没用（甚至更糟），"低头"才是收凸嘴的动作
   - 注意：别仰太大（会放大鼻孔、下巴、双下巴）
3. **遮挡** — 手托腮、捂嘴、拿道具（花、咖啡杯、书）放在嘴前，自然不刻意
4. **控制嘴部表情** — 轻微抿嘴、微笑（别大笑露齿），嘴角形态能削弱凸感
5. **景别** — 避免特写嘴部，用近景/中景靠表情带动，别硬刚嘴部细节

**光线配合** — 凸嘴是"往前突"的立体轮廓，立体感越强越明显，所以光线的目标是**把脸拍平**：
- **柔光 + 正面/顺光** — 脸部轮廓过渡平，凸嘴不明显（和古风"修平"同理）
- **避免硬光 / 90° 侧光** — 硬光在嘴下沿拉锐利阴影，把轮廓"勾"出来，凸嘴更抢眼
- **高调亮调 / 轻微过曝** — 亮部吃掉下半脸阴影，凸嘴细节被淹没
- 一句话：光影是把脸"捏"成三维的工具，藏凸嘴时你要的是**二维**。选择柔和顺光，把下半脸阴影减到最少

> 机位不能改变模特，但能决定观众**看哪里、看到什么程度**。

## 机位的意义

不同的机位不是"哪个好看"，是**让观众感觉自己和被摄者的关系不同**。

- 平视 = "我和你一样"
- 仰视 = "你很高大/有力量"
- 俯视 = "我在看你，你在我下面"
