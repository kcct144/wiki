# 广角镜头

别名：wide-angle lens、28mm 镜头。

> 基于 28mm（全幅）使用经验。装备：佳能 6D + EF 28-135mm f/3.5-5.6 IS USM 广角端。

## 一、广角的三个核心特性

### 1. 视角宽
- 28mm 视角约 **75°**，比人眼看到的范围更宽
- 能在一个画面里容纳更多元素

### 2. 透视效果最强
- 焦段越广 → 近大远小越夸张
- 焦段越长（长焦）→ 透视越压缩，前后物体大小感越接近
- **近大远小、近高远低、近宽远窄**——广角把这三条透视规律放大到极致

### 3. 边缘畸变
- 人脸/物体放画面边缘会被拉伸变形
- 越靠近边缘越明显

## 二、什么时候用广角

| 场景 | 理由 |
|------|------|
| 照片太平、没空间感、没层次 | 广角的强透视天然制造纵深感 |
| 想交代人物在什么环境里 | 环境人像，广角框进足够的背景信息 |
| 室内空间不够（会议、合照、小房间） | 不广角拍不齐，没得选 |
| 想玩视觉冲击力 | 利用近大远小做夸张对比 |
| 风光、建筑 | 框得多，透视强，有气势 |

## 三、什么时候别用广角

| 场景 | 原因 |
|------|------|
| 背景杂乱，无关元素多 | 广角框得越多，乱的元素越入画 |
| 只想突出人物本身 | 背景信息太多反而干扰主体 |
| 重要人物放边缘 | 畸变拉脸，领导/客户不好交代 |
| 半身人像 | 离太近畸变显鼻子大下巴尖，离太远人太小 |

## 四、用法

### 一个前提
所有视觉冲击力和趣味性，都要建立在**画面和谐**的基础上。广角的夸张透视是锦上添花，不是雪中送炭——如果画面本身构图失衡、元素杂乱，冲击力只会让人觉得是废片。

### 创造性用法

**一条红线**：主要元素不能有夸张变形（人脸、主体人物），次要元素可以利用畸变（前景道具、背景线条）。知道什么该变形、什么不该变，比单纯追求冲击力重要。

**实战案例 — 夸张婚纱照**：新人放画面中心保持正常体型和脸型，婚纱裙摆/头纱/前景花瓣靠近镜头边缘利用畸变拉大铺满 → 主体美，画面有冲击力。

利用近大远小、近高远低、近宽远窄制造视觉冲击：

- **低角度仰拍** → 主体高大突出，背景收缩延伸
- **前景夸张** → 前景放一个物体（花/手/道具），靠近它，主体在稍远处 → 大小对比产生戏剧性
- **引导线** → 利用透视收缩的线条（路、栏杆、走廊），把视线引向主体
- **三层纵深感** → 前景 → 主体 → 远景，广角的强透视让三层关系更明显

### 室内场景

- 会议/合照 → 广角是首选，空间不够没得选
- **重要人物放画面中心区域**，避免边缘畸变
- 站得开就尽量用 35-50mm，畸变更小

### 合照提醒

- 两边的人会被拉伸变形，尽量收拢站位
- 宁可站远用稍长焦段 + 大家挤一挤，也别为拍齐而让边缘的人变形太夸张

## 五、广角的本质 — 建筑师思维

- **广角镜头主动性很强**——不主动找角度、安排前景、利用透视，拍出来就是一张平庸的"手机拍"
- 长焦可以"我在远处抓拍"，广角不行。广角逼你必须想：**我要站在哪、放什么在前景、怎么利用透视**
- **广角出片 = 主动创造**；**长焦出片 = 发现和捕捉**。两种完全不同的拍摄思维
- 有些画面不是"刚好出现"的，而是**自己创造出来的**——广角就是做这件事的镜头

## 六、快速决策

| 条件 | 选择 |
|------|------|
| 环境干净 + 想交代空间关系 | → 上广角 |
| 环境杂乱 + 只想突出人 | → 换长焦 |
| 照片太平没层次 | → 试试广角 |
| 空间不够拍不齐 | → 只能广角 |
| 想主动创造画面 | → 广角 |
| 想安静观察抓拍 | → 长焦 |
