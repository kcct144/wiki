# 人像创作流程

别名：人像摄影流程、portrait workflow。

> 一张人像始于一个"虚"的情绪/念头，要把它变成"实"的色彩、形状、场景、动作。
> 整个创作分**三个时间阶段**：拍摄前·构思 → 拍摄时·前期 → 拍摄后·后期。

## 流程总览

```
拍摄前·构思（想清楚） → 拍摄时·前期（拍下来） → 拍摄后·后期（调出来）
```

核心思维：**由点延伸出面，由虚到实**。从大脑的思绪（虚）转化为看到的颜色形状（实）。

## 阶段一：拍摄前 · 构思

按下快门前，把所有"想"的事做完。

### 选题
- 从一个"点"出发——一个情绪、一个主题、一个词
- 向外延伸成"面"——一套完整的视觉世界
- 由虚到实：情绪/感受（虚）→ 色彩/形状/场景（实）
- 感知转化为具体，别停留在"我要拍一组照片"，要落到"拍什么情绪、什么颜色、什么画面"

### 风格定位
确定整套基调：
- **影调（光影+色彩）**：光影 → 高/中/低、柔/硬；色彩 → 冷暖对比 / 调和 / 纯灰调（低饱和）
- 风格定调后整套统一，比单张好看更重要

### 前期准备
- **模特、服装、妆造**（妆容+发型）、**场景、道具**

### 中期构思
把风格落成具体拍摄方案：
1. **取景构图** — 具体场景、具体用光、具体色彩、具体情绪
2. **美姿动作** — 站姿 / 坐姿 / 蹲姿 / 躺姿 / 趴姿 / 靠姿 / 跪姿
3. **机位选择** — 高 / 低 / 平视 × 正面 / 侧面 / 背面
4. **景别** — 远景 / 全景 / 中景 / 近景 / 特写

## 阶段二：拍摄时 · 前期

按下快门时的技术清单，把构思落实成参数：
- **曝光三要素** — 光圈 / 快门 / ISO
- **测光模式** — 评价 / 中央重点 / 点测光
- **曝光补偿（±EV）** — 相机测光被骗时手动纠正明暗
- **白平衡** — 色温设定
- **白平衡偏移** — 色调倾向
- **照片风格设置** — 相机内直出风格
- **焦距** — 焦段选择（广角 / 标准 / 长焦）

## 阶段三：拍摄后 · 后期

拍摄结束后的处理，让画面到达"实"的终点：
- **影调调整** — 明暗、对比、调性（呼应风格定位）
- **色彩调整** — 色温、饱和度、色调统一
- **五大基准调片** — 黑色 / 阴影 / 曝光 / 高光 / 白色（配合直方图）
- **修图** — 瑕疵、皮肤处理等

> 后期不是"补救"，是把拍摄时定好的方向**落到终点**。前期越想清楚，后期越省力。
