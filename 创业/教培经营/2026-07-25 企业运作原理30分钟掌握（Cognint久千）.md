## 核心框架

企业 = 一台机器，由**设计**和**人**构成，服务于**目标**。

```
目标 → 设计 + 人 → 机器（公司）→ 结果 → 对标目标 → 诊断修正 → 新目标 → 循环
```

## 一、目标（德鲁克三大假设）

### 1. 组织环境假设
- 市场规模、增长率、市场份额（红海/蓝海）
- 相关政策法规
- 海外市场时间差（国外已验证的模式搬回国内）

### 2. 组织特殊使命假设（价值主张）
- **痛点 = 商机**：是否足够痛？是否有人满足？是否有复购？
- **使命**（公司存在的合法性/正义性）
- **愿景**（具象的未来位置）
- **价值观**（隐形规则，从招第一个人开始塑造）

### 3. 核心能力假设
- 商业模式与盈利模式、竞对分析（SWOT/波特五力）
- 资源配置能力、打平周期、融资计划、退出机制

## 二、结果

可量化的结果（营收/利润/日活/市占率）与不可量化的结果（通过同异对比认知）。

## 三、设计（内部游戏规则）

| 模块 | 内容 |
|------|------|
| 文化设计 | 使命愿景价值观 |
| 战略管理 | 战略目标→清晰度/视野→路径→分解（时间×部门→里程碑） |
| 组织架构 | 岗位图谱→定岗定职定编→岗位职责说明书 |
| 流程设计 | 跨部门协作 |
| 财务管理 | 预决算、审计 |
| 信息管理 | 信息化、系统化、信息安全，消除数据孤岛 |
| 价值创造 | 产品体系、项目管理、品质控制 |

### 战略层次

动作层→执行层→中层管理→C级高管→资源层（股东/董事）→愿景层（创始人/实控人）

## 四、人：选育用留

- **选**：价值观 > 能力 > 技能（长期主义）；格局 > 韧性 > 概念能力
- **育**：学徒制（艺术性高）vs 学院制（技术性强）
- **用**：绩效考核 + 年终评审 = 激励相容
- **留**：情感留人 + 待遇留人
