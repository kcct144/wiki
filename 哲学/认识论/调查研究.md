# 调查研究

别名：调查就是解决问题、没有调查没有发言权。

从毛泽东的《反对本本主义》和《改造我们的学习》中提炼的方法论。

## 核心命题

- **没有调查，没有发言权**（反对本本主义）
- **调查就是解决问题**——"调查就像十月怀胎，解决问题就像一朝分娩"
- 一切结论产生于调查情况的末尾，不是先头

## 方法论要点

1. 开调查会，讨论式调查
2. 选对人：深切明了情况的人（老中青、各职业）
3. 事先准备调查纲目（大纲 + 细目）
4. 亲身出马，不能单靠书面报告
5. 深入一处地方或一个问题，了解底里
6. 自己做记录

## 反模式

- 主观主义：不问环境、不看全体、不触本质，自以为是发号施令
- 形式主义：盲目执行"本本"，不根据实际情况审察
- 片面性：只看局部不看全体，"闭塞眼睛捉麻雀"
