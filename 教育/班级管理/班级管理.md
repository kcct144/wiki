# 班级管理

别名：班级管理方法。

区别于课堂管理的班级层面运营方法论。

## 管理生命周期

立威 → 管不住 → 积分制 → 造反 → 怀柔

## 核心原则

- **班规三原则**：简单/明确/可执行
- **抓两头带中间**：小组每层抓一人
- **温柔且坚定**：执行策略的核心态度
- **期待理论运用**：期望×工具性×效价

## 管理手段

- 五类手段：激励/惩罚/讲道理/讲条件/下命令
- 四类思路：给予任务顺便完成目标/转移矛盾立规矩/分类问题/借力打力
