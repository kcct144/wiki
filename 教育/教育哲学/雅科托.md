# 雅科托（Joseph Jacotot, 1770–1840）

别名：Joseph Jacotot、约瑟夫·雅科托。

法国教育家，曾在荷兰担任外教。他的荷兰教学实验成为朗西埃《无知的教师》全书的核心案例。

## 关键实验

在荷兰教授法语时，雅科托不懂荷兰语，无法为学生讲解。他将一本双语版《太雷马克历险记》发给学生，让他们借助翻译自学法语。几个月后，学生写出了相当不错的法语读后感——在没有教师讲解的情况下获得了表达能力。

## 核心发现

- **讲解不是学习的必要条件**：学生可以仅凭自己的意志和双语材料学会一门语言
- **意志决定论**：人能否做成某件事，可能只取决于意志，而非天赋或教师的讲解能力
- **普遍教育法**（Universal Teaching）：任何人都可以教任何人任何东西，即使教师对所教内容一无所知

## 历史影响

雅科托的实验启发了两个世纪后的朗西埃，后者在《无知的教师》中将这一案例上升为教育哲学的系统批判：**解释权就是统治权**，教育体系通过"讲解"这一看似中性的手段，实际上在制造和维持智力不平等的秩序。

## 当代回响：不备课

凯凯的 [不备课](<2026-06-04 不备课.md>) 展示了雅科托式教学在当代课堂中的实践：

- 雅科托：不懂荷兰语 → 不讲解 → 发双语书 → 学生自学成功
- 凯凯：不备课 → 不预设教案 → 当场做题给学生看 → 学生自己发现规律
- 共同模式：教师承认自己也会卡住，把思考过程打开，让学生看到"学习长什么样"
- 共同效果：学生不再依赖讲解，开始主动发现规律
