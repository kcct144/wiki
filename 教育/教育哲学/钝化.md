# 钝化

别名：stultification、使人变笨。

朗西埃在《无知的教师》中提出的核心概念（法文 *abrutissement*，英文 stultification），指传统讲解式教学在不知不觉中使学生丧失自主学习能力的过程。

## 核心机制

钝化最隐蔽的地方在于：**它往往来自最用心的老师。** 不是偷懒的老师在钝化学生——是把知识嚼碎了喂给学生的老师。

1. **制造距离**：教师预设鸿沟——"你们不会，我来帮你们"。问题是，在教师说"你们不会"之前，学生未必真的不会。
2. **替代学习**：教师替学生完成学习中最关键的环节（推理、理解、归纳），学生拿到成品知识。核心能力"从一团乱麻里理出头绪"被代劳了。
3. **建立依赖**：学生内化"不靠老师讲，我就学不会"——这不是懒惰，是被替代后的理性结论。
4. **自我复制**：受讲解长大的学生当了老师，第一反应就是去讲解。

> 你甚至不是在"没教"他们这个过程——你是在阻止他们经历这个过程。你把路铺得太好了，他们根本不需要自己找路。

## 典型场景

教师教英语选词填空。亲自做了大量题目，总结出三条思路（看搭配、看词性、看意思），做成思维导图让学生背。效果很好，成绩提上来了。但如果换一种新题型，学生无法自己总结出规律——**因为总结规律这个能力，恰恰是教师比学生厉害的地方，而教师从没让学生练过。**

## 一线解法

朗西埃的"完全不讲解"太极端，但思想可以落地。教师做三件事替代讲解：**创造动机、引导注意、帮学生把话说出来。** 非紧急情况不讲解。不一次性总结好塞给学生，而是一边练一边发现一边总结。规律是大家一起凑出来的，教师只是那个问问题、帮着记下来的人。
3. **建立依赖**：学生逐渐内化"不依靠讲解，就不能理解"的自我认知
4. **自我复制**：受讲解人长大后成为讲解人，进一步巩固钝化体制

## 课堂微观版：纠错致傻

[纠错致傻](<../教学方法/2026-05-28 纠错致傻.md>) 揭示了钝化在课堂中最常见的微观形态——**在不该纠的时候纠**：

- 学生正在练习主要目标（如 have done 结构），教师纠正了一个次要细节（gone vs went）
- 学生听到的不是"这个细节错了"，而是"我又错了"——学习状态被毁掉
- "你把他从'我今天学会了 have done'这个主要矛盾，拽到了'我连 go 的过去分词都不知道'这个次要矛盾上"
- 这个操作和钝化的机制完全相同：教师的介入**替代了学生自己经历学习过程的机会**

## 解药：不备课

[不备课](<2026-06-04 不备课.md>) 展示了钝化的反面实践——教师在黑板前当场做题、卡住、推翻、再试：

- 教师把自己降到和学生一起想的位置，**预设了智力的平等**
- "规律是学生自己发现的，我只是帮他们把话说清楚的人"
- "课本教了三年英语，我教了三年怎么学一个东西"——活教材 > 死讲解
- 直接呼应[雅科托](<雅科托.md>)实验：不懂荷兰语的老师不讲解，学生反而学得更好

## 关键论断

- "不是这个学生在学习，而是这个老师在学习"
- "受讲解人长成讲解人，一切周而复始"
- "让书呆子教育书呆子，循环往复，永无止境"
- 越是热心的老师，越致力于完善讲解方式，就越深地推进钝化
- "最好的纠错，是学生不觉得被纠了，但听到了对的版本"（来自纠错致傻）

## 对立面

钝化的反面是**智力解放**（émancipation intellectuelle）——相信每个学生有能力自行理解和学习，教师的任务是创造一个让自学得以发生的环境，而非替代学生思考。

> [!assumption] 假设
> 讲解式教学必然导致钝化。验证方式：对比长期接受讲解式教育的学生与主要依靠自学的学生，在遇到全新问题时自主学习能力的差异。
