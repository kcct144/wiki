# 未明子谈穷人小孩一定要有电脑（材料笔记）

别名：未明子电脑论、穷人小孩电脑。

> 来源：B站视频 BV1LqzLY3Eto 字幕稿
> 作者：未明子
> 上传日期：2024-11-30

## 核心论题

穷人家庭的孩子必须有电脑、会用电脑，仅靠手机远远不够。

## 核心论点

### 一、电脑 vs 手机：生产工具 vs 消费终端

手机的本质不是通用计算机，而是"电话机的延展"：

| 维度 | 电脑 | 手机 |
|------|------|------|
| **输入方式** | 键盘快、鼠标精确 | 手指点按，输入慢 |
| **文书处理** | Office 三件套流畅运行 | 差到几乎不能用 |
| **存储成本** | 1T NVME ~200元 | 256G 手机就要加很多钱 |
| **接口扩展** | USB、HDMI、调试口 | 极少 |
| **设计理念** | 通用计算机——你生产东西 | 采集器——你输入信息 |
| **制作能力** | 能写小说、做设计、剪视频、编代码 | 基本只能拍短视频 |

核心判断：**手机把你变成"随时待命的终端"，电脑让你成为"能生产公共品的主体"**。

### 二、正在发生的数字阶级分化

- 打工家庭的小孩"都不会电脑"——家里没电脑，出租屋没书房，学校电脑课形同虚设
- 中产/小市民家庭会给孩子配电脑、鼓励编程
- 设备差异转化为能力差异：**新媒体文书工作、自动化、编程、剪辑、硬件调试……这些用电脑的工作穷人小孩根本接触不到**
- 国际类比：越落后的国家"人人有手机，基本上没电脑"，因为电脑迸发的生产力会动摇既有的控制秩序

### 三、"玩电脑"本身就是最好的教育

未明子用了大量篇幅讲游戏的教育价值，逻辑链很清晰：

**为什么会折腾游戏 = 什么都会：**

1. 找破解版 → 学信息搜集、装虚拟光驱、过验证
2. 打 mod、改金手指 → 理解文件结构、修改数据
3. 调画质、超频 → 摸索硬件和系统设置
4. 装模组 → 理解依赖、版本、加载顺序（跟编程打包一模一样）
5. 架设单机网游端 → 涉及服务器、数据库概念

> "编程后面也就是全都是那个模组呀——全都是去装载别人的库，没技术含量的。"

**游戏选择有高下之分：**

| ✅ 推荐 | ❌ 不推荐 |
|---------|----------|
| DOTA2（需要复杂操作和系统知识） | 王者荣耀（封闭系统、诱导付费） |
| 上古卷轴（打 mod、改数据） | 抽卡氪金手游 |
| 模拟器游戏（GBA/NDS/PSP，上万经典） | 刷宝式网游 |
| 星际、红警、植物大战僵尸 | |
| 自己找破解单机（锻炼折腾能力） | |

### 四、具体的产品方案

未明子团队正在做一款针对穷人家庭的**小主机**（18cm 见方，自带七寸屏，五六百元）：

- H81 平台，核显，够用 win11 不卡
- 可以玩 2D 游戏和早期 3D 游戏
- **可升级**——将来换板U套、换更高分辨率屏幕组件
- 附送电脑课/编程课/硬件课/职业技能课（修显卡、电工证等）
- 还会出"老人版"和"可插显卡的游戏版"

## 讨论延伸

### 手机游戏的意识形态功能

未明子这个视角和我之前的一些观察能联系起来。他把手机定位为"把人物化的设备"，手游则是"喂猪食"——这不是道德评判，是在说：

- 手游在封闭系统里做重复的、被设计好的操作，**不产生任何可迁移的计算机能力**
- 复杂单机游戏（尤其要自己折腾破解、mod、配置的）则**必然带来计算机素养的提升**
- 两者的分化不是偶然的：手机生态的设计初衷就是 **把你固定在消费端**

### 拆电脑=拆解社会

视频末尾他把话题拉回更大的图景："工人家庭小孩天然具有设备技术能力" = "截取生产资料的预备队"——会电脑不只是求职技能，而是**理解现代社会运行逻辑的入口**。

这也解释了为什么"落后国家人人有手机但没电脑"——控制信息的生产和分发渠道，比控制消费更根本。

## 潜在概念重叠

此篇涉及的话题与以下现有概念可能有交叉：

- **[教育理念转向的社会基础](<../教育哲学/教育理念转向的社会基础.md>)** — 当下一代的信息环境被手机主导，教育的形态和理念必然被重塑
- **[意识形态批判](<../../哲学/意识形态/意识形态批判.md>)** — 手机生态的"消费即自由"预设，本身就是意识形态运作的典型案例：用户知道手机不自由（不能改文件系统、不能装任意软件、被跟踪），但仍然接受
- **[实践](<../../哲学/社会实践/实践.md>)** — 未明子的主张本质上是在说：技能不是学出来的，是在折腾（实践）中长出来的

如果后续再有来源涉及数字鸿沟/设备分层，可考虑建 **数字素养鸿沟** 或类似概念。
