# 社交框架

别名：社交分析框架、信息分享五阶段。

凯凯原创的社交分析框架。回答了三个问题：社交的本质是什么？（本体论）、怎么判断当前状态？（认识论）、往哪走？（目的论）。

## 本体论：社交是什么

**社交的根本目的是服务劳动。** 人在生产及其他社会活动中发生的相互联系、交流和交换。不是为了社交而社交——社交是手段，劳动是目的。

### 四种基本策略

| 策略 | 说明 |
|------|------|
| 合作 | 共同目标，协同行动 |
| 竞争 | 争夺有限资源 |
| 冲突 | 目标或利益对立 |
| 调适 | 含寒暄、礼仪、小恩惠交换——降低摩擦，维持关系 |

### 信息分享五阶段

社交深度的递进，每层有对应的目的和话题范围：

| 阶段 | 目的 | 典型话题 |
|------|------|----------|
| 初识 | 调适、增加了解 | 姓名、年龄段、哪里人、做哪一行、周末活动 |
| 熟悉 | 获取更多个人信息 | 工作经历、兴趣爱好、家庭背景、近期计划（避敏感话题） |
| 喜欢 | 建立信任和友谊 | 理想、感情生活、价值观、成长经历、遇到的挑战 |
| 信任 | 相互帮助、资源共享 | 秘密、重大决策、深层恐惧、未来期望 |
| 莫逆 | 长期交底 | 家庭规划、财务状况、健康问题、共同梦想 |

## 认识论：怎么判断当前状态

从四个维度观察社交表现：
- **表现形态**：合作 / 竞争 / 冲突 / 调适
- **需求来源**：生产驱动、社会符号建构的社交需求、共同体事件
- **阶段定位**：当前处于信息分享五阶段的哪一层
- **策略匹配**：当前策略是否符合阶段目的

> [!assumption] 假设
> 信息分享五阶段是单向递进的（初识→莫逆）。实际上可能存在跳跃或倒退——比如共同经历危机事件可能跳过熟悉直接进入信任。验证方式：在不同关系类型（师生/家长/同事/朋友）中观察阶段转换路径。
